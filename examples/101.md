# 대만 타이베이 101 (Taipei 101) — 구조 기본정보

> **목적**: midas Gen / NX 골조(구조) 모델링을 위한 기초 자료 정리
> **범위**: 외형 개략 + 구조 시스템 + 주요 부재/치수/재료 중심
> **주의**: 아래 수치는 공개 자료(위키피디아, CTBUH 구조설계 논문, 구조 해설 자료 등)를 종합한 값으로, 자료마다 ±편차가 있습니다. 실무 설계용이 아닌 **개념 모델링·학습용 참고치**로 사용하세요.

### 평면 (Floor Plate)

- 평면 형상: **대략 정사각형** (모서리에 **재진입(sawtooth/double-notch) 2.5 m 노치** 적용 → 와류 저감)
- 층 바닥면적: **약 2,500 m² ~ 4,300 m²** (높이에 따라 변화, 상부로 갈수록 축소)
- 참고: 정사각형 가정 시 한 변 대략 **50 ~ 65 m** 수준 (개략 추정)

### 전체 구성 (수직 프로파일)

```
        [ 강재 첨탑 (spire) ]        ← 상부 TMD 보조댐퍼
        [ 9번째 모듈 (전망/기계층) ]  ← 축소 평면
        [ 8개 모듈 × 각 8층 = 64층 ] ← 위로 벌어지는 반복 모듈
        [ 25층 저층부 (역피라미드형 base) ] ← 전도저항·강성 확보
        [ 포디움 / 지하 5층 ]
```

## 3. 구조 형식 (Structural System)

**메가프레임 (Mega-frame) = 가새코어(Braced Core) + 아웃리거(Outrigger) + 메가컬럼(Mega-column)** 의 하이브리드 시스템.
태풍(횡풍) 대응 강성과 지진 대응 연성을 동시에 만족하도록 설계됨.

주요 구성 요소:

1. **중앙 가새 코어 (Braced Core)** — 횡력 1차 저항
2. **외주부 메가컬럼 8본 (Super/Mega Columns)** — 전도모멘트를 축력으로 저항
3. **아웃리거 트러스 (Outrigger Truss)** — 8층마다 코어와 외주 기둥 연결
4. **벨트 트러스 (Belt Truss)** — 외주부 기둥 간 힘 분배
5. **모멘트 골조 (SMRF, 2차 시스템)** — 경사 외피면을 따라 배치, 지진 연성 확보

## 4. 주요 부재 (Structural Members)

### 4-1. 메가컬럼 (Super / Mega Column) — 외주부 8본

| 항목 | 내용 |
|---|---|
| 개수 / 배치 | 8본 (각 면당 2본) |
| 단면 형식 | 강재 박스 + 고강도 콘크리트 충전 (**CFT형**) |
| 최대 단면 | 약 **2.4 m × 3.0 m** (자료별 2.4 × 3.1 m) — 높이 따라 변화 |
| 강판 두께 | **50 ~ 80 mm** (용접 스플라이스) |
| 콘크리트 충전 | 하부~**62층**까지 충전 (69 MPa) |
| 강재 연장 | **90층**까지 연속 |
| 부가 요소 | 내부 크로스타이(벌징 방지), 전단스터드, 철근 보강 |

### 4-2. 코어 기둥 (Core Columns)

| 항목 | 내용 |
|---|---|
| 개수 / 배치 | **16본 강재 박스 기둥** (4열 정사각형 코어) |
| 골조 | 층간 모멘트 골조로 완전 가새 처리 |
| 콘크리트 벽 피복 | 기초 ~ **8층**까지 콘크리트 벽으로 피복 |
| 콘크리트 충전 | ~**62층**까지 충전 (69 MPa) |

### 4-3. 아웃리거 & 벨트 트러스

| 항목 | 내용 |
|---|---|
| 아웃리거 | **8층마다** 배치, 인접 2개 층 보를 수직 가새로 연결 (대나무 마디 개념) |
| 벨트 트러스 (하부) | **9, 19, 27층** — **2개 층 높이(2-story deep)** |
| 벨트 트러스 (상부) | 8층마다 **1개 층 높이(1-story deep)**, 외주 기둥 X-브레이싱 |
| 기능 | 외주부 하중을 각 면 2본의 메가컬럼으로 수집·전달 |

### 4-4. 저층부(26층 이하) 추가 기둥

- 메가컬럼이 건물 외형을 따라 **경사(sloping)**
- 각 면 중앙에 **2.0 m × 1.2 m** 기둥 추가
- 각 모서리에 **1.4 m 정사각형 경사 박스 기둥** 추가

### 4-5. 바닥 슬래브

| 항목 | 내용 |
|---|---|
| 형식 | 강재-콘크리트 **합성 슬래브 (composite deck)** |
| 두께 | 표준 **135 mm** |
| 보 | RBS(dogbone) 디테일 적용한 감소단면보 (연성 확보) |

## 6. 기초 (Foundation)

| 항목 | 내용 |

| 형식 | 매트 기초 + 현장타설 말뚝(bored pile) |
| 말뚝 (타워) | **380본** (포디움부 167본 별도) — 일부 자료 총 601본 |
| 말뚝 직경 / 간격 | **1.5 m** / 약 4 m 격자 (엇배치) |

| 라프트(전면기초) 두께 | **3.0 ~ 4.7 m** (기둥 하부에서 두껍게) |
| 지중 연속벽(slurry wall) | 두께 1.2 m, 깊이 최대 47 m |
| 지반 조건 | 연약 점토·콜루비움, 40~60 m 하부 사암(연암), 지하수위 지표 -2 m |

## 7. 제진장치 (Tuned Mass Damper, TMD)

| 항목 | 내용 |
|---|---|
| 위치 | **87 ~ 92층** (구체는 88층 부근 노출) |
| 질량 | 약 **660 톤** (726/728 톤 표기도 있음) — 건물 총질량의 약 0.24% |

## 9. midas Gen / NX 모델링 관점 정리

개념 모델(외형 + 주요 골조)만 필요하다는 요청을 반영한 우선순위 정리입니다.

**필수 반영 요소**
- 층수 101층, 기준 층고 4.2 m (저층 6.3 m) → 대략 정사각형 평면(모서리 노치는 개념모델에서 생략 가능)
- 중앙 코어 16본 박스기둥(4×4 배열) + 코어 가새
- 외주부 메가컬럼 8본 (각 면 2본) — CFT 단면, 하부 경사
- 8층마다 아웃리거 트러스 (코어 ↔ 메가컬럼)
- 벨트 트러스: 9·19·27층(2층 높이), 이후 8층 간격(1층 높이)
- 합성 슬래브(135 mm)는 강막(rigid diaphragm) 또는 판요소로 단순화

**단면/재료 입력 가이드 (개념치)**
- 메가컬럼: 박스 2.4×3.0 m, 판두께 50~80 mm, 내부 콘크리트 69 MPa (CFT)
- 코어기둥: 강재 박스, 62층까지 콘크리트 충전
- 강재: Fy ≈ 420 MPa 기준(부위별 412~510 MPa)
- 콘크리트: fck ≈ 69~70 MPa

**단순화 권장 (개념 모델)**
- 첨탑, TMD, 저층부 추가기둥, sawtooth 노치는 형상만 반영하거나 생략
- 메가컬럼 경사(26층 이하)는 절점 좌표로 반영, 상부는 수직 처리
- 하중은 자중 + 개략 활하중/풍하중으로 시작 후 상세화
