## 의미와 한계
- **검증된 것**: 지진계수 사슬 전체(부지계수 → T0 → SaD → Ra·Fu → (SaD/Fu)m → V_D·V*·V_M 과 지배 판정), 竖向분배, 수직지진 Fuv. 이 부분은 이제 "원문을 같은 사람이 두 번 읽은" 자체 테스트가 아니라 **제3자(ETABS·GTStrudl 기반 실무 계산서)와 일치**한다.
- **검증 안 된 것**: 2022 개정 부지계수표·臺北盆地 T0 경로(계산서는 堅實地盤 Fa=Fv=1), 장주기(T>0.7, Ft>0, SaD 감소 구간), 1.4Ta 상한, 풍 2014 고유 항목(0.06 상수·5 m 하한·G (2.9)·Kzt — 조문 대조만), 층간변위각(ETABS 모델값이라 비교 불가), 112 콘크리트 조합(계산서는 1.4D+1.7L 세대), 10층 이상 규모.
- 계산서의 T_dyn(0.582/0.482)은 ETABS 모델 고유치라 앱 모델과는 비교 대상이 아님. 앱에서 같은 평면을 만들어 Gen 고유치를 비교하는 것은 별개 작업(층중량 246/149.5/240.9 t 재현 필요 — 벽·마감 하중 상세가 계산서 3장에 있음).
