# 대만 RC 구조계산서 요청 메모 (앱 대조용)

작성 2026-11-12 · 용도: MIDAS 대만 지사/고객사에 계산서 1부를 요청할 때 전달할 조건 · 비커밋 가능(내부 요청 문서)

## 왜 필요한가

앱(Gen NX RC 도구)의 대만 지진·풍·층간변위 산정은 규범 원문을 읽어 구현했고 자체 테스트로만 확인했다. **실무 계산서와 숫자를 직접 대조한 적이 없다.** 한 건이라도 외부 계산서와 맞추면 "앱 숫자를 믿어도 되는 범위"를 말할 수 있다. KR 은 Gen 네이티브 KDS 와 일치를 확인했지만 TW 는 Gen 에 해당 기능이 없어 계산서가 유일한 외부 기준이다.

## 원하는 건물 (우선순위 순)

1. **RC 특수抗彎矩構架(SMRF) 1동**, 지상 10~25층, 지하 0~2층, 평면이 대체로 정형(직사각형 격자).
2. 설계 규범: 建築物耐震設計規範(현행, 111/112년 적용본) · 建築物混凝土結構設計規範 112年版 · 建築物耐風設計規範 2014.
3. 전단벽·코어가 있어도 좋지만, 없는 순수 골조가 1차 대조에 더 좋다.
4. 臺北盆地 사례면 더 좋다(T0 기반 스펙트럼 경로를 함께 확인 가능).

## 계산서에 들어 있어야 하는 항목

### 입력
- 평면 치수·경간·층고, 기둥/보 단면(층별), 슬래브 두께, 콘크리트 f'c, 철근 등급
- 용도별 활하중·마감하중(SDL), 칸막이 하중
- 지진: 工址 SDS·SD1(또는 SS·S1 + 地盤分類), 臺北盆地면 T0, 用途係數 I, 結構系統 R, 분석 방법(등가정적/동적)
- 풍: 基本設計風速 V10(C), 地況, 用途係數, 陣風反應因子 G

### 결과 (숫자가 표로 있어야 함)
- 층별 중량 W_i 와 총 W
- 주기: 경험식 T_a 와 해석 주기 T₁(X·Y), 1.4T_a 상한 적용 여부
- 지진: 설계 밑면전단 V(X·Y), V*/V_M 비교, 층별 지진력 F_i, Ft
- 풍: q(z), 층별 풍력, 밑면전단
- 층간변위각(지진·풍, 방향별 층별)
- 비틀림 검토(δmax/δavg), 우발편심 처리 방식
- 동적해석을 했다면: 질량참여율, 응답스펙트럼 SCALE(總橫力 ≥ 정적 V × 0.9/1.0)
- 하중조합 목록(112 5.3.1)

### 있으면 좋은 것
- 해석 모델 파일(Gen/ETABS 등) — 같은 모델을 앱으로 다시 만들어 1:1 비교 가능
- 심사 의견서(審查意見)가 있으면 어떤 지표가 실제로 문제 되는지 알 수 있음

## 전달 시 참고

- 프로젝트명·발주처·주소는 가려도 된다. 숫자와 입력값만 필요하다.
- 계산서는 로컬 전용으로 보관하고 저장소에 커밋하지 않는다(`*.pdf` gitignore).
- 대조 결과는 항목별 "일치 / 차이 n% / 원인"으로 정리해 `docs/`에 남긴다(계산서 원문은 인용하지 않음).

## 대조 범위 밖 (계산서에 없어도 됨)
- 배근·도면·물량 — 이번 대조는 해석 입력과 횡력·변위까지.
