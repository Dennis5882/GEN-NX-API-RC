### 규범 버전 차이 — 대조 전에 환산해야 하는 것
계산서는 **94/95년(2005/2006) 耐震規範**, 앱은 **111년(2022)판**. 식 구조는 같고 아래만 다르다.

| 항목 | 2005 계산서 | 앱(2022) | 대조 방법 |
|---|---|---|---|
| 起始降伏放大倍數 αy | RC 1.5 | 1.0 | V 를 1.5배 환산해 비교(또는 테스트에서 αy 를 인자로) |
| 週期上限係數 Cu | 1.2 (T_des = min(Tdyn, 1.2Ta)) | 1.4Ta 상한 | T 를 계산서 값으로 고정해 SaD·Fu 단계만 비교 |
| 工址 Fa/Fv, 臺北盆地 구역 | 2005 표 | 2022 표(분지 一·二·三區 T0) | 堅實地盤 Fa=Fv=1.0 사례라 영향 없음 |
| 풍하중 | 2005 당시 풍규범 | 2014 풍규범 | 풍은 이 계산서로 대조하지 않음(별도 자료 필요) |
| 수직지진 | 2F 계산서에 식 있음(SaD,v=½SaD, R=3) | 2.18 구현과 같은 구조 | 계수 단계 비교 가능 |

### 이 자료로 검증되는 것 / 안 되는 것
- **되는 것**: 지진계수 사슬(SDS·SD1 → T0 → SaD → Ra·Fu → (SaD/Fu)m → V_D·V_M·V*), 층력 竖向 분배·층전단·전도모멘트, RS 정적 대비 비교의 형식, 질량참여·주기 보고 형식, 층간변위각 한계 0.005 판정, 하중조합 구성(수직지진 ±0.3 포함).
- **안 되는 것**: 10층 이상 고층(이 계산서는 4층·Hn 9 m 라 Ft=0, 장주기 영역 없음), 2022 개정 Fa/Fv·臺北盆地, 2014 풍규범, 112 콘크리트 규범 조합(계산서는 1.4D+1.7L 세대).
- 결론: **"식을 맞게 구현했는가"의 1차 오라클로 충분**. "현행 규범 실무값과 같은가"는 여전히 지사 계산서가 필요하다.

## 2. 대조 절차 — **1차 완료(2026-11-12)**: 결과 [tw-oracle-check-2008.md](tw-oracle-check-2008.md), 테스트 `tests/tw.oracle2008.test.mjs` 19항목 전부 일치. 아래는 당초 절차.
1. 앱에 4층 계산서와 같은 입력(평면·층고·단면·DL/LL·SDS 0.7/SD1 0.4·I 1.0·R 4.8? → 계산서는 R=3(VD)/R=4(VM) 표기 확인 필요)을 넣고, 테스트(`tests/tw.test.mjs`)에 αy·Cu 를 2005 값으로 바꾼 케이스를 추가해 V_D 83.2 t / V_M 83.3 t / V* 70.7 t(X), 93.0/97.2/69.3 t(Y)와 비교.
2. 층력 분배: 층중량 246.0/149.5/240.9 t(1~3F), 층력 16.43/19.64/47.22 t(X) 재현.
3. 층간변위각은 ETABS 모델 의존이라 ±10% 수준에서 경향만 확인.
4. 결과는 `docs/tw-oracle-check-2008.md` 로 남긴다(원문 숫자 인용은 대조표에 한함).
